# MindSpace Backend

API backend diseñada para gestionar la lógica de autenticación y datos de la plataforma MindSpace.

## Enlaces del Proyecto

- **API en producción:** [https://psicdenise.ddns.net](https://psicdenise.ddns.net)

## Tecnologías Utilizadas

- **Node.js**
- **Express**
- **MongoDB**
  para autenticación segura

## Configuración del Proyecto

### Instalación

Clona este repositorio y ejecuta:

```bash
npm install


API desplegada en: https://psicdenise.ddns.net
```
